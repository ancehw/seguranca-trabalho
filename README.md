# 🛡️ Segurança no Trabalho - Portal Profissional

Um site completo dedicado à segurança ocupacional com recursos educacionais, normas regulamentadoras e sistema de denúncias.

## 📋 Sobre o Projeto

Esta plataforma oferece:
- ✅ Conteúdo educacional sobre normas de segurança (NR)
- ✅ Blog com artigos sobre segurança ocupacional
- ✅ Sistema de gestão de documentos
- ✅ Painel administrativo completo
- ✅ Sistema seguro de denúncias
- ✅ Site de links úteis (Bio Links)
- ✅ Autenticação de usuários
- ✅ Responsivo e otimizado para SEO

## 🚀 Como Usar

### Localmente:
1. Clone o repositório
```bash
git clone https://github.com/ancehw/Seguranca-Trabalho.git
```

2. Abra o arquivo `index.html` no navegador
```bash
cd Seguranca-Trabalho
open index.html  # macOS
# ou
start index.html  # Windows
# ou
xdg-open index.html  # Linux
```

### Online (GitHub Pages):
Acesse diretamente: https://ancehw.github.io/Seguranca-Trabalho/
